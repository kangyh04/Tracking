### Tracking

Unreal Engine 5.6ベースのQ-Learningアルゴリズムを活用した迷路探索AIプロジェクト

#### プロジェクト概要
「ARC Raiders」の敵AIからインスピレーションを受け、移動学習するAIを作成し、A*を利用して学習時間を短縮するシステムです。このプロジェクトは、強化学習のQ-Learningアルゴリズムを使用して、迷路で最適経路を学習し、探索するAIエージェントを実装します。Unreal EngineのC++プラグインシステムを活用し、拡張可能な構造で設計されています。

* リアルタイム学習可視化: 学習プロセスを移動単位で3D環境で視覚的に確認

### Tracking

An AI project for maze solving using the Q-Learning algorithm based on Unreal Engine 5.6.

#### Project Overview
Inspired by the enemy AI in "ARC Raiders," this system creates an AI that learns movement and uses A* to reduce the learning time. This project implements an AI agent that uses the Q-Learning reinforcement learning algorithm to learn and find the optimal path in a maze. It is designed with an extensible structure using Unreal Engine's C++ plugin system.

#### Key Features
* Q-Learning Algorithm: Reinforcement learning-based pathfinding
* Dynamic Maze Generation: Random maze creation using Eller's Maze algorithm
* Real-time Learning Visualization: Visual confirmation of the learning process per movement step in a 3D environment
* A* Pathfinding: A* algorithm for comparison with the optimal path
